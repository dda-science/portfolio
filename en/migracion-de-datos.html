What changes

With the usual method

  • The usual method overwrites what is in the target.
  • It can only be used three times.

With this tool

  • First a trial run that shows what would change, without touching anything.
  • It only writes when told to.
  • Each record arrives linked to its related records.

What I did

  1. I ruled out the usual method because it overwrote what was in the target.
  2. I built a tool that does a trial run first and only writes when told to.
  3. I documented every decision and every step applied.
