Què canvia

Amb la via habitual

  • La via habitual sobreescriu el que hi ha a la destinació.
  • Només es pot fer servir tres vegades.

Amb aquesta eina

  • Primer un assaig que mostra el que canviaria, sense tocar res.
  • Només escriu quan se li dona l'ordre.
  • Cada registre arriba enllaçat amb els seus.

Què vaig fer jo

  1. Vaig descartar la via habitual perquè sobreescrivia el que hi havia a la destinació.
  2. Vaig construir una eina que primer assaja i només escriu quan se li ordena.
  3. Vaig deixar per escrit cada decisió i cada pas aplicat.
